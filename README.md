# MazeMind — Autonomous Maze Solver

**Module:** CSCI323 Modern Artificial Intelligence  
**Group:** FT100  
**Institution:** University of Wollongong / SIM Global Education

## Project Overview

MazeMind is a Python-based autonomous maze-solving project that investigates reinforcement learning and classical pathfinding algorithms.

The project uses a custom Gymnasium environment to evaluate navigation performance across predefined and generated mazes.

## Algorithms

- Q-Learning
- SARSA
- Breadth-First Search (BFS)
- A* Search
- Online Flood Fill

## Experiments

The project investigates maze complexity, learning rates, reward structures, route optimality and navigation with moving obstacles.

## Technologies

Python, Google Colab, Gymnasium, NumPy, Matplotlib and Pandas.

## Running the Project

1. Download the `.ipynb` notebook from this repository.
2. Open it in Google Colab.
3. Run the notebook cells in order, starting with dependency installation.
4. Review the generated maze visualizations and experimental results.
